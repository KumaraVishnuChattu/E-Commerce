Javascript:

    Definition:
        Javascript is a scripting language as well as programming language.
        JS is Dynamically typed programming
        JavaScript having single Call Stack.
    
    Uses:
        - Using JavaScript we can build Dynamic web applications.
        - Using JS , we can add functionalities to the web pages.
        - Here we can achieve DOM(Document Object Model) functionalities , using that we can manipulate HTML and  CSS.
        - Here we can fetch Data from the server(APIs) and also send data to the server.
    
    History:
        - 1991
        - Mocha(1995) by Net Scope(Browser Company)
        -  LiveScript
        -  JavaScript
        - ECMA added new feature then, release 1st version -> ES1(ECMA Script version1)
        - ES6 is the stable version currently used mostly.
        - ES16 is the current max version (released April,2026)
    
    Implementation:
        -Inline
                example: <button onClick="">..</button>

        -Internal
            - <script>..</script> element is written at the end of body element, because the HTML should be loaded first.
            - we can use "defer" attribute to write script element anywhere.
            - ex: <script defer> .. </script>
